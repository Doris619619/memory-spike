# 提示词

`v0.txt` 是方案 §7 的 `text` 代码块逐字提取（仅统一 LF 换行、保留结尾换行）。文件直接发给模型，不能为了文件头说明而向提示词中插入注释；用途由本文件记录。

来源：UI#309 的 `c110c82b04935e33988b4bcff2e108dac9a16018`，`docs/memory/MEMORY_EXTRACTION_SPIKE.md`，版本 v0.2。仓库内 [方案快照](../docs/MEMORY_EXTRACTION_SPIKE.md) 的正文与该版本一致。

V0 和 V1 使用相同提示词、相同输入；V0 增加协议级结构化约束，V1 不加约束并按首个 `{` 到末个 `}` 解析。

原始 v0 不覆盖。方案允许一次修订：新增 `v1.txt`，记录修改理由，配置 `prompt_version=v1`，建立新实验目录，报告分别展示两轮，不用修订后的成功替换第一轮失败。
